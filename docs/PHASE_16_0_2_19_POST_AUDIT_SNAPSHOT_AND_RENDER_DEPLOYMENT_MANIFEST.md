   - Source verification: `mongo_store.py` checks `PERSISTENCE_BACKEND=mongodb`. If MongoDB Atlas is unreachable in this mode, it executes:
     ```python
     raise RuntimeError('Activated strictly when PERSISTENCE_BACKEND=mongodb but MongoDB Atlas is unreachable. Refusing silent fallback to ephemeral storage.')
     ```

   - Source verification: `validate_and_get_auth_secret()` verifies `AUTH_SECRET_KEY` in production mode (`APP_ENV=production`) and refuses default or insecure keys.

   - Automated scan verified 0 private keys, 0 live API tokens, and 0 production database URIs across all 438 files in Manifest A and all 118 files in Manifest B.
